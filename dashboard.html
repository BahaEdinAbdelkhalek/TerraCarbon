How to wire live data:
1. Run terraform output -json > terraform_outputs.json and serve it alongside this file.
2. Get an Azure bearer token: az account get-access-token --query accessToken -o tsv
3. The Carbon Intensity API is free — no token needed.
4. Log Analytics queries need the workspace ID from the output above. Token must have Log Analytics Reader role.
